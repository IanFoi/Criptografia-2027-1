Investiga los 5 OSINT más usados.

\textbf{Respuesta:}
En el ámbito de la ciberseguridad, las investigaciones digitales y las pruebas de penetración, las cinco herramientas y plataformas de OSINT más utilizadas y reconocidas son:

\begin{enumerateColor}
    \item \textbf{Shodan:} Considerado el motor de búsqueda de dispositivos conectados a Internet por excelencia~\cite{shodan_guide}. A diferencia de Google, que indexa páginas web, Shodan escanea e indexa los banners de respuesta de puertos abiertos, servidores web, cámaras de seguridad, bases de datos, dispositivos IoT y sistemas de control industrial (SCADA), revelando fallos de configuración y versiones expuestas.
    \item \textbf{Maltego:} Plataforma interactiva de minería de datos y análisis de grafos relacionales~\cite{maltego_paterva}. Permite transformar datos dispersos (nombres de personas, correos, dominios, IPs y redes sociales) en diagramas de red visuales que muestran de manera inmediata las conexiones y dependencias existentes entre diferentes entidades.
    \item \textbf{theHarvester:} Herramienta de consola ampliamente usada en la fase inicial de reconocimiento. Está diseñada para recolectar correos electrónicos de corporativos, nombres de colaboradores, subdominios, direcciones IP y URLs a partir de decenas de fuentes públicas como buscadores, servidores de claves PGP y bases de datos públicas.
    \item \textbf{SpiderFoot:} Plataforma de automatización OSINT con más de 200 módulos de recolección de datos integrados. Basta con proporcionar un objetivo (nombre de dominio, bloque de IPs, nombre de usuario o correo electrónico) para que realice un barrido integral de certificados, registros DNS, fugas de contraseñas y listas de reputación maliciosa.
    \item \textbf{Recon-ng:} Un entorno de trabajo (\textit{framework}) modular y extensible con una interfaz de comandos muy similar a Metasploit, pero enfocado exclusivamente en inteligencia de fuentes abiertas. Cuenta con módulos independientes para consultar bases de datos públicas, APIs de servicios web y registros de infraestructura.
\end{enumerateColor}
