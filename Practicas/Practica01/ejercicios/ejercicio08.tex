¿Qué es sniffing?
 
Es una técnica que consiste en interceptar y analizar el tráfico de datos dentro de una red con el fin de obtener la información que se comparte entre los dispositivos conectados. La técnica es utilizada en auditorías de seguridad o diagnósticos de red, así como para capturar información sensible como contraseñas, datos financieros o credenciales de acceso~\cite{snif}.
 
Se utilizan las herramientas de sniffing para capturar paquetes de datos que se transmiten dentro de una red; estos datos corren el riesgo de ser robados si es que el tráfico no está cifrado apropiadamente, por lo que para evitar la vulnerabilidad ante atacantes que usan sniffing es vital utilizar protocolos de comunicación seguros como HTTPS, redes privadas virtuales (VPN) y tener la información apropiadamente cifrada.
