¿Qué herramientas proporciona el SO Kali?

Incluye una extensa lista de herramientas preinstaladas que, como vimos anteriormente, están orientadas a la ciberseguridad, las pruebas de penetración (pentesting) y el análisis forense. La lista de herramientas que contiene el sistema es enorme, pero se pueden clasificar en~\cite{kali_docs}:
\begin{itemizeColor}
    \item Herramientas de reconocimiento.
    \item Herramientas para desarrollo de recursos.
    \item Herramientas para acceso inicial.
    \item Herramientas para ejecución.
    \item Herramientas de persistencia (acceso continuo).
    \item Herramientas de escalado de privilegios.
    \item Herramientas de evasión de defensa.
    \item Herramientas de acceso a credenciales.
    \item Herramientas de descubrimiento.
    \item Herramientas para movimiento lateral.
    \item Herramientas para recopilación de datos.
    \item Herramientas para ataques \textit{Command and Control} (C2).
    \item Herramientas de exfiltración de datos.
    \item Herramientas de análisis forense.
\end{itemizeColor}
